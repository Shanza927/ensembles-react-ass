# React Assessment

This is a simple React application bootstrapped with [Vite](https://vitejs.dev).

The goal of the application is pretty simple: display the value stored in an object outside of React. However, there are a few bugs you must solve for it to behave correctly.

Lastly, we ask you write a custom hook to encapsulate the main value handling logic and add one or two tests for it (see `src/__tests__/state.test.ts`).

**You may use any library/resources you wish, but you will be asked to justify your choices!**

## Acceptance Criteria

- [ ] The application must not render infinitely
- [ ] The local value of the App component and the SharedState store must always be in sync
- [ ] Create a new hook that ensures the values are always in sync
- [ ] Add a test to verify your hook works
